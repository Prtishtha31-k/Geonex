# Geonex
A web app to explore countries using REST Countries API

Explore the world, one country at a time



Project Description

Geonex is a web application that helps users explore information about different countries around the world. The idea behind this project is to make it easy to search and learn about countries in a simple and interactive way.

The application will fetch real-time data from a public API and display useful details like the country’s flag, capital, population, and region.



Purpose

The main purpose of this project is to practice core web development concepts such as:
	•	Working with APIs using JavaScript
	•	Using functions like filter, map, and sort
	•	Building a clean and user-friendly interface

This project also helps in understanding how real-world applications manage and display data.


API Used
	•	REST Countries API
	•	Source: https://github.com/public-apis/public-apis

This API provides detailed information about countries, which will be used in the application.




Features (finalized for future milestones)

Search
Users will be able to search for any country by typing its name.

Filter
Users can filter countries based on regions such as Asia, Europe, Africa, etc.

Sort
Countries can be sorted:
	•	Alphabetically (A–Z)
	•	By population (low to high or high to low)

Country Details
Each country will display:
	•	Flag
	•	Capital
	•	Population
	•	Region

Additional Features (Optional)
	•	Dark mode / light mode
	•	Option to mark favorite countries
	•	Fully responsive design for mobile and desktop




Tech Stack
	•	HTML
	•	CSS
	•	JavaScript 
	•	Fetch API
